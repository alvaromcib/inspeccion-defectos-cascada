What didn't work: the VLM deciding the type

The first version let the VLM choose the defect type. With a 3B model on CPU, it did worse than the detector.

Why a cascade

CostA VLM on every frame is expensive and slow. Here it only sees a few crops per defect.
ReliabilityConsensus filters out erratic answers but can't fix a bias: so the type is decided by the model trained for it, and the VLM adds what the detector can't provide.
PrivacyThe VLM runs locally with Ollama: plant images never leave the factory.
ExplainableEach defect carries a type, a severity and a natural-language reason for the quality report.
Measured, not assumedEach stage is evaluated separately. If a larger model or a better prompt classifies better than the detector, the fusion rule changes based on data.
